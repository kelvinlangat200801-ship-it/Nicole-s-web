NICOLE LOVE WEBSITE — QUICK START

Files:
- index.html: the complete, mobile-friendly website. No paid tools or libraries needed.

PUBLISH FREE FROM YOUR ANDROID PHONE (GitHub Pages):
1. Open https://github.com in Chrome and create/sign in to a free account.
2. Tap + / New repository. Name it: nicole-love
3. Set it to Public, then create the repository.
4. Choose Add file → Create new file. Name it exactly: index.html
5. Open the supplied index.html file in a text editor, select/copy all the code, and paste it into GitHub's editor.
   (Alternatively, use the upload option if your GitHub interface offers it.)
6. Commit the file.
7. In the repository, open Settings → Pages.
8. Under Build and deployment, choose Deploy from a branch; choose main and /(root), then Save.
9. Wait a few minutes. GitHub will show your public website address, usually:
   https://YOUR-USERNAME.github.io/nicole-love/
10. Open that address to test it, then send the link to Nicole.

TIPS:
- Replace text in index.html before publishing if you want to add personal memories.
- Keep the repository public for free GitHub Pages on a public repository.
- The website does not collect data, require a login, or play audio automatically.
